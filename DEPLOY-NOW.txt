MATCH INDEX V16.3.1 — TURSO FIX

This replaces the accidental Supabase regression in V16.3.

1. In Vercel -> Project -> Settings -> Environment Variables, keep/add:
   API_FOOTBALL_KEY
   TURSO_DATABASE_URL
   TURSO_AUTH_TOKEN

2. You do NOT need Supabase variables.
3. You do NOT need to run schema.sql manually. The app creates its Turso tables on first backend use.
4. Upload/replace the repo with this folder and redeploy.
5. Open /api/health. You want:
   version: v16.3.1-turso-team-first
   apiFootball: true
   turso: true
   database: true
6. Open Match Index -> System -> Sync now. Leave the page open 2-3 minutes on first build.

The team-first discovery / prediction / Oxford UI remains unchanged from V16.3.
